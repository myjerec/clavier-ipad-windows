# Contribuer

Ouvre une issue en indiquant ta version Windows/iPadOS, la version du compagnon, les étapes et le résultat attendu. Ne joins aucune donnée d’appairage ni document privé. Pour le développement et les tests, voir DEVELOPPEMENT.md.

Les contributions doivent conserver la validation des commandes, l’accès limité au réseau local et l’absence d’exécution shell arbitraire. Décris les tests effectués et distingue toujours essais simulés et validation avec un vrai iPad. Les contributions au code sont proposées sous licence MIT.
